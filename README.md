# R-estimators-with-a-generic-scale-function
This code proposes an implementation of the R-estimator of the shape matrix for RES and Circular CES distributed data under any possible scale function. The related paper is:
S. Fortunati, J. -P. Delmas and E. Ollila, "Nuisance Parameters and Elliptically Symmetric Distributions: A Geometric Approach to Parametric and Semiparametric Efficiency," in IEEE Transactions on Information Theory, vol. 72, no. 9, pp. 6902-6927, Sept. 2026, doi: 10.1109/TIT.2026.3706237
https://arxiv.org/abs/2506.23213
